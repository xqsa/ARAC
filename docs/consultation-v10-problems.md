## 一、问题设置（自包含描述）

### 任务

只通过黑盒函数评价，在固定预算（发现阶段 ≤ 130k FE）内恢复变量的重叠组结构：
哪些变量同组（组内不可分）、哪些变量被多个组共享（重叠）。

### 测试基准 AOB（构造已知，仅用于离线审计）

- 4 个底函数族（Ackley/Elliptic/Rastrigin/Schwefel）× 6 个重叠度：
  F1–F6 的 overlap_degree = **0/1/3/5/7/10**；
- F1：20 个不相交组（尺寸 25–100），真共享变量 = 0；
- F6：真共享变量 = 190；共享变量出现在相邻组的边界；
- 关键构造细节：**变量经过随机置换**（Pvector），组在观测坐标中完全打散；
  组内全耦合（旋转矩阵），组间零交互。

### 当前流水线（v10.3，五阶段）

1. **粗筛**（15,870 FE）：固定随机 hash 分成 32 个区域，区域对混合差分
   `I(A,B) = f(x+Δ_A+Δ_B) − f(x+Δ_A) − f(x+Δ_B) + f(x)`，按响应范数归一；
2. **变量签名**（13,205 FE = 1 + d + P + d×P + P×size，P=12 个固定随机
   探针 batch，每 batch 16 变量）：每个变量对**同一共享探针基**测混合差分，
   得 12 维签名向量。同组变量的签名在打中本组的探针上共同触发；
3. **谱排序**（0 FE）：签名余弦相似度矩阵 → Laplacian → Fiedler 向量排序
   （零签名变量确定性排尾）；
4. **递归二分**（~1k FE）：在重排后的变量序列上按中点递归分裂，每次分裂
   做左右混合差分测试；显著分裂记录为区域关系；
5. **条件探针 + 双侧证据门**（~55k FE）：显著分裂边界的邻域变量做逐变量
   条件探针；hyperedge（共享变量声明）须通过三元组判据：
   - j 与目标侧某成员 t 单对耦合（t 逐成员测试选出）；
   - j 在其序邻域（半径 8 扫描）内与某 h 耦合；
   - **h 与 t 在全部 anchor 上可分**（不交互）。
   直觉：真共享变量跨越两个互不交互的组领地；组内碎片伪影的 h、t 同组必交互。

### 当前已达成（不要在这些问题上花时间）

- F1（无重叠）假阳性：98 → **1**（双侧门生效）；
- F6 精确率 0.87–0.92；稀疏网格 ov6 共享召回 0.67–1.0；
- 所有证据可精确计费（逐级 FE 收据），F1 不再产生重叠声明。

## 二、主问题：共享变量召回率低（R6 = 0.07–0.12）

### 现象

R6（190 个真共享变量）只恢复 13–22 个。召回被两个环节双重压制：

### 瓶颈分解（R6 实测）

1. **靶向覆盖 ≈ 0.43**：只有 43% 的真共享变量（81/190）进入边界候选列表。
   候选 = 显著分裂边界在重排序中的邻域变量。理论上共享变量的签名是两个
   组触发模式的并集，应在 Fiedler 序中处于两簇之间（界面处）；实测它们
   **多数位于组领地内部**，不在界面——全局排序质量不足；
2. **转换率 ≈ 0.27**：已覆盖的 81 个中只有 ~22 通过三元门。真值归因
   （81 个的拒绝原因分类）：50 个因为扫描半径内找不到"与 t 异侧"的耦合
   邻居 h；25 个因为半径 8 内没有任何耦合邻居。

### 根因

Stage B 的**全局排序质量**。签名（12×16 探针，13k FE）能支撑局部近邻
（top-4 命中率为随机的 30–90 倍，已验证），但 Fiedler 全局序噪声大
（1000 维、每组 25–100 变量、每组只有 ~4 个探针会打中）。排序不准 →
二分边界不对齐组结构 → 共享变量不在边界 → 靶向覆盖低。

### 已考虑的候选方向（未实施，征求意见）

- (a) 增加探针数 P（预算换排序质量；13k → 25k FE 量级）；
- (b) 放弃线性排序，改为**谱聚类成组**（signature 相似度图上做聚类，
  组直接作为区域，绕过二分对齐问题）；
- (c) **种子扩张**：先确认少量高置信共享变量，从其邻域向两侧扩张定位
  组边界（自举式）；
- (d) 用粗筛的区域对关系图引导细化顺序（优先分裂高交互区域）；
- (e) RDG3 式递归归因：分裂后把变量逐个归入交互更强的一侧，代替纯
  中点二分。

### 想请教的问题

在 ~13k–25k FE 的交互测量预算内、1000 维、组尺寸 25–100、随机置换的
设定下：**有什么成熟的全局变量排序/组定位技术**能比 Fiedler 序更稳？
(b)–(e) 哪条路线最值得先试？有没有我们没想到的标准做法（文献里的
DG2/RDG3/DECC 系或谱方法在这个预算量级下的实际表现）？

## 三、次问题 A：R2 异常（低重叠下全假阳性）

### 现象

R2（overlap 1，19 个真共享）：34 个 hyperedge **全部是假阳性**（精确率
0.00），而 R4（overlap 5）精确率 0.50、R6（overlap 10）0.87——**重叠度
越低假阳性率越高**，方向反常。

### 矛盾点

构造上非共享变量只与同组成员交互。三元门误放行的必要条件是某个单对
测试出错：要么 I(j,h) 跨组假触发（解析上应为 0，阈值 1e-10，噪声地板
~1e-13，不该触发），要么 I(h,t) 同组假静默（同组弱耦合对低于阈值）。
但这两个误差方向都无法自然解释"低重叠反而更糟"。

### 想请教的问题

是否见过这种"结构越稀疏、判别越差"的阈值行为？合理的排查方向是
真值提取对齐（我的 truth 从 vendor 元数据重建）还是测试统计量本身？

## 四、次问题 B：二分树与组结构的对齐（碎片化）

中点二分的分裂点在 dyadic 位置，真实组边界（25–100 变量的任意位置）
几乎必然不对齐 → 叶子（最小 8 变量）切碎真组 → 组内耦合以跨叶交互
形式出现。双侧门已在"声明层"补偿（不再误报重叠），但**区域关系层**
仍被碎片污染（R1 有 58–64 条区域关系，全部是同组碎片间的关系），
影响后续 HIERARCHICAL 协调的调度质量。

已考虑：merge 阶段（相邻强交互叶合并）/ 同质性停止规则（子对全交互
即停）。想请教：对齐二分树与未知块结构的标准技术（RDG 系的停止准则、
层次聚类的连接距离设计）里，哪个在"组内全耦合 + 组间零耦合"这种
0/1 结构下最稳？
