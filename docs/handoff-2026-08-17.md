## 一、研究背景与算法框架

**最终算法 ARAC-OC**（单一架构，已裁定不存在"双域架构"概念）：

```
Phase-I：发现重叠结构和成员置信度
Phase-II 重叠协调器
  ├─ 冲突残差计算
  ├─ 冲突等级判断
  ├─ GCB：决定处理顺序、范围和预算
  └─ 调用 SMP / CTP / AOR
真实目标函数评价
strict-best 接受与状态反馈
```

核心命题：**协调器根据在线冲突状态动态决定"处理哪里、多大范围、
调用哪个动作"，而不是固定调用某一个搜索算子**。

**测试基准**：稀疏重叠网格（1000-D、24 活跃维、4 组，Gate 37-40 用）
+ AOB-24（4 底函数族 × 6 重叠度 0/1/3/5/7/10，SOTA 论文基准）。

**SOTA 差异化**（源码审计确认，`docs/sota-oracle-confirmation.md`）：
HCC-ES（GECCO 2025）的分解直接读取 AOB 构造文件（oracle），零黑盒
检测。ARAC-OC 在无先验结构信息下工作，解决 SOTA 未涉及的更难问题。

**术语裁定（重要）**：GCB = 协调器（dispatcher="gcb_coordinator"）；
四个搜索 episode 为 CTP / SMP / GSS / AOR，其中 GSS（图调度扫掠）
的历史收据名冻结为 "gcb"（episode_kind="gss" 映射），避免"GCB 调度
GCB 动作"的概念混淆。

## 二、创新想法（最终表述）

主创新：**冲突状态驱动的重叠协调调度**——协调器四问（处理哪里/
多大范围/多少预算/哪个动作）在线回答，优于任何固定选择。

支撑创新：有限黑盒预算内的分层重叠证据构建（Phase-I v3：召回
0.908 / 精确率 1.0，SOTA 无同类工作）。

升级路线（用户提出，已基本实现）：episode 级调度 + **跨 episode
全局 strict-best 接力（handoff）**——四个完整动作组合在统一调度下
形成接力（GSS/CTP 修结构 → SMP 带记忆局部搜索 → AOR 全局校正），
目标是**同 checkpoint 同预算下超过最优 standalone**。

## 三、已完成的工作（按证据链）

### A. 稀疏重叠域（✅ 收口）

| Gate | 内容 | 结果 |
|---|---|---|
| 37-40 | 最小内核（streak+hub 派发） | 24+24 配对不劣 + 4 严格胜，跨族泛化 |
| 46 | 统一循环 vs 冻结内核 | 24/24 不劣、22 胜、内核逐位复现审计通过 |
| 47 | τ 阈值校准 | **诚实失败**：C_j 幅值对拓扑可修复性无判别力（负结果，Gate 47 协议存档） |
| 47i | streak+价值门配置 | 18/18 不劣 + random/ov6 **−15.05**（首个超内核收益，来自 AOR 升级窗） |

**稀疏域结论**：统一循环（streak + 价值门）为已验证生产姿态。
关键教训入档：C_j 不能做阈值门（Gate 47）；噪声尺度窗口在多模态
地形上做锚点扰动是负资产（Gate 47b → 价值门修复）。

### B. AOB 域——Phase-I 与动作级派发（✅ 冻结）

- **soft-RDDSM v3**（召回 0.908/精确 1.0）：完整候选集粗分组 →
  16 变量小区域递归细化 → soft group cover → 完整交集移除 + 双侧
  确认 + 5 探针可分性 + 最小残差门。关键修复：互斥块+成员计数
  的数据流 bug（召回结构性为零）、3-vs-4 FE 计账、可分性探针
  相干符号。F1-F6 真值 = 20 组链式相邻重叠（0/19/57/95/133/190
  共享），从 vendor F*-info/s/p 离线重建。
- **Gate 41a/41b**（动作级派发，冻结对照列）：两特征规则
  （tail_log10_gain + structural_relation_density），41a 离线
  24/24 ≤1.005×、对 HCC 21/3/0；41b 在线 25-seed **20/4 对 HCC**
  （历史 18/1/5）、几何均值 0.244；S6 失败（7.79×）= seed 140
  特征漂移误派 gcb + ctp 自身 1.28×，规则边界覆盖缺口如实记录。
  逐 seed mean±std 表存
  `artifacts/overlap_action_dispatch_gate41_online/final_table_mean_std.csv`。

### D. episode 收编与 handoff 接力（✅ 机制闭环，✅ 3M 判定完成）

**收编**（四动作完整包装为可分段 v2 episode）：
- ctp/gcb：Gate 50a 真实规模分段等价逐位（修复 v2 两个恢复 bug：
  全空间段维度比较、population_size 重建）；
- aor(recovered)：零均值锚 + 原始 action_seed；**实证：v2 会话
  路径与 legacy port.run 非逐位**（手工驱动代际循环），配对两侧
  必须同为 v2；
- smp(recovered)：代对齐步进契约（vendor 批形状敏感实测：单行
  与批式差 ~1e-14，episode 永不拆代）；**双逐位**（与 legacy 及
  任意分段均逐位一致，四者中最强）。

**调度器**（`episodes.py`，schema v3）：四 episode 常驻私有镜像
账本（单次计费入全局 strict-best）；counted B/W 感知（**B/W 排序、
C 仅诊断**——Gate 47 约束）；证据块序 = scope 机制 v1（CTP/GSS
扫掠先搜冲突活跃块；SMP/AOR 全局组合不受约束）；四强制可执行
探针（饥饿响亮失败）；全局 materiality（私有收益不驱动调度）；
sequential contextual 探针语义（边际贡献，非同基线能力估计）；
探针税校验（share ≤0.25，税后须余可执行预算）。

**handoff 机制（双概念分离）**：
- archive handoff：`adopt_global_archive()`（严格单调+私有 FE 不变
  断言），四方全收——AOR 的 local_gain 因此获得相对 x* 的真实基线；
- search-state handoff：CTP/GSS 下一 segment、SMP 下一 visit 经
  私有账本锚点自然接棒（episode 内部零改动）；AOR =
  fresh_by_design（保持零均值独立搜索；单测证明注入前后其会话
  state_hash 逐位不变）；
- OOB 边界策略：全局最优可为 SMP 无裁剪 offspring 的越界点；
  有界锚机制（CTP/GSS）拒绝（refusal="oob_incumbent"），
  SMP/AOR 接受——3M 实测真实触发（R2 拒 2、R6 拒 3、S5 拒 2）；
- 收据：EpisodeHandoffReceipt（from/to/mode/adopted/refusal/
  双侧 snapshot_hash）+ 消融开关。

**Gate 50c（3M 六臂配对，终判）**：

| case | 最优 standalone | OC-ON | OC-OFF | 判定 |
|---|---|---|---|---|
| A3 | aor 78,180 | 78,517 (×1.004) | 78,244 | 不劣过 |
| R2 | aor 221,157 | 422,018 (×1.91) | 434,065 | 不劣败 |

gate_passed = false（性能层 2/4）。**但 R6 是项目史上第一个完整的

（smp 2.05+0.84 / ctp 0.13 / aor 1.01）+ ON 优于 OFF（关 handoff
优势消失）+ 接力链收据可见（含 OOB 拒绝与 aor→smp 回棒）+ 假粘性
对照（gcb local 0.85/global 0.00 被正确降权）。

## 五、遇到的问题（开放与已解决）

### 已解决（要点）

1. soft-RDDSM 数据流 bug（互斥块+成员计数 → 召回结构性为零）；
2. vendor 批形状敏感（单行 vs 批式 ~1e-14）→ 代对齐契约；
3. v2 会话恢复两个 bug（全空间维度/population）→ Gate 50a 修复；
4. v2 与 legacy 非逐位 → 配对两侧同为 v2 的设计裁定；
5. sigma→inf（收敛至下限）→ sigma 巨大有限（上限=活跃跨度）→
   **根因：AOB vendor 变换 |x|≥5e4 即 NaN（Tasy 指数含 √z）**
   → `_EpisodeLedger` 幅值护栏 |x|≤1e4（四 case 实测有限，
   NaN 清洗+裁剪+计数入收据；R2/off smp 14 次修复后正常运行）；
6. SMP 转移上限假死锁（随预算缩放）；
7. Gate 46 判据方向反转 bug（如实记录后从冻结收据重出判定）；
8. 41b 收据盖章 bug（复用路径缺 schema_version）。

### 开放

1. **晚熟排序问题**（见优先级 1）；
2. R2/S5 非劣性（同根因）；
3. 探针税 40% 的效率上限（发现保证的价格）；
4. SMP 会话持久化升级（sense 车道仍每周期重启提案，未吸收历史
   smp 的全程状态记忆——48b 差距归因之一）。

4. 若写论文：方法节按单一架构树 + episode 接力；先清文档漂移

逐臂容错（单臂失败不炸全场）；600k 机制筛选 ≠ 3M 性能结论。
