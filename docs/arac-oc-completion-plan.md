## 1. 最基本的问题与它的答案

研究的根本问题自始至终是一个：

> **阶段二对共享变量，做什么和"不考虑重叠"不一样的事？**

它**不是**"阶段二什么时候该跑哪个动作"——那是第二个、难得多的、可选的
问题。第一个问题只需要两个答案，且两个都已被自己的 gate 证明：

1. **用重叠证据选动作**（Gate 41a/41b：两特征派发规则，24 case × 25 seed，
   对 HCC 20 胜 4 负、几何均值比 0.244）；
2. **共享变量的取值由完整目标函数仲裁**（Gate 29/30：proposal-neighborhood
   对 proposal-only 36/36 全胜，中位增益 37.9514；机制有 FEA 文献先例）。

工程底座（strict-best archive、exact FE、fail-closed、receipt/state hash 链）
已验证完毕。**"重叠感知的阶段二"在科学上已经闭合。**

## 2. 复杂度失控的归因（如实记录）

失控点：把"让阶段二具备重叠感知"实现成了"造在线调度器"。证据回看：

- 重叠感知需要的创新是**仲裁**——活在动作执行**内部**的机制；
- 在线调度是外加的可选问题，其证据始终残酷：组合真正赢过全部 standalone
  的只有 R6 一次（Gate 50c，3M）；S5 的最好结果（Gate 50，1.000 精确等于
  ctp standalone）恰是调度器"什么都不做"时取得的；
- v4.0→v5.3 的跷跷板（修 R2 破 S5、修 S5 破 R6）源于用单轴规则表达
  双轴状态（诊断见 lit-review §一，G11 回放验证保护半边成立）。

结论：不是研究失败，而是在已答完的问题上叠加了一个难十倍的新问题。
处置：**第一个问题收成，第二个问题降级为分析。**

## 4. 最终架构（主线冻结）

```text
Phase-I：soft-RDDSM v3 黑盒重叠发现（冻结，180k FE 契约）
    ↓ OverlapCheckpoint（块结构 + 共享变量 + incumbent，不可变）
Phase-II：证据驱动派发（Gate 41a 两特征规则，冻结）
    ↓ 选中动作执行 3M
重叠创新层：动作执行期间，共享变量经完整目标函数仲裁
    - 候选：incumbent / owner proposals / weighted consensus / weighted median
    - tournament 用真实完整目标；strict-best 写回全局 archive
    - 无共享变量（ov0）时仲裁自动静默 → 对非重叠问题零税
```

第三条完成标准据此重新表述（预注册修订）：

> **同 checkpoint 同预算下，"派发+仲裁"不劣于"裸派发"（处处），且在
> 高重叠 case 上严格更优（至少一处）。**

原表述（在线组合调度不劣于历史最佳派发）降级为支线研究问题。

## 5. Gate 53（唯一剩余新实验，预注册骨架）

**目标**：验证仲裁接进派发路径后的净效应，并产出论文核心曲线。

- **两臂**（同 checkpoint、同 seed、精确 3M、fail-closed 审计）：
  - A：Gate 41b 派发路径（裸动作，复用冻结收据可行则复用）；
  - B：同一派发 + 共享变量完整目标仲裁（FEA 式 tournament + strict-best）。
- **问题谱**：AOB 重叠度全谱 F1–F6（ov 0/1/3/5/7/10，真值共享
  0/19/57/95/133/190，vendor 元数据权威）× ≥3 seed（含 fresh seed）。
- **判定（全部同时，预注册后不许回调）**：
  1. ov0（F1）：B 与 A 差在容差内（**无税条款**——仲裁静默、开销可忽略）；
  2. 高重叠（ov≥5，即 S5/R6 对应 case）：B 严格优于 A（至少 1 处）；
  3. 全部 case：B 不劣于 A（容差预注册，建议 ×1.05）；
  4. **核心曲线**：log-ratio(B/A) 对重叠度单调不减的趋势检验
     （预注册检验方法与显著性阈值）；
  5. 契约审计：exact FE、strict-best 单调、仲裁候选计数、archive 恢复。
- **失败语义**：任一失败 → 仲裁按 case 关闭（回退纯派发），失败项如实
  写入论文边界；不允许 gate 内调参重试。
- **工程量边界**：仲裁机制已在统一循环中存在（Gate 29/30 路径），
  本 gate 是**接线 + 判定**，不是新机制开发。

## 7. 代码精简计划（三刀，顺序固定）

实测基线：`src/arac` 58 文件 21,332 行；`episodes.py` 2,852 行、12+ 机制族；
`gcb.py` 680 行近乎无引用；`experiments/` 146 文件为冻结证据，不动。

1. **第一刀（随时，零风险）**：当前状态打 git tag（如 `v5.3-prealation`），
   此后老版本活在 tag 里，不活在 if-else 里；
2. **第二刀（Gate 53 判定后）**：主线上不再被引用的调度机制**删除**（不是
   加开关）；`episodes.py` 目标 ≤1,000 行；每刀后全量 pytest + ruff 全绿；
3. **第三刀（论文定稿前）**：`legacy_unified` 线（`loop.py`/`planner.py`/
   `contract.py`/`operators.py`，Gate 46–48 代）与 `gcb.py` 整体移出 `src`
   进 tag 或 `vendor/legacy/`（冻结 cell 以收据为锚、不需重跑，移动安全）。

纪律：删除计划预注册（列清单）→ 执行 → 全量回归 → 判定，与版本纪律同款。

## 8. 论文故事线

**定位**：HCC 测的是 oracle 结构上界（构造文件直读，零黑盒检测——源码级
证据）；ARAC-OC 测的是**黑盒可达能力**：从零发现重叠结构，用证据驱动
优化，并对共享变量做完整目标仲裁。HCC 结论自留开放问题（"更智能的
exploration/exploitation 平衡"），本文的分析节直接回应。

**主张（全部有 gate 证据）**：

1. 黑盒重叠发现：召回 ~0.9、精度 1.0、180k FE（vs HCC 的 oracle 输入）；
2. 证据驱动派发：对 HCC 20/4、几何均值 0.244；
3. 共享变量仲裁：36/36 胜 proposal-only；Gate 53 的优势-重叠度曲线；
4. 分析节：在线组合的存在性（R6）与边界（跷跷板刻画 + 象限稳定性）。

**引用缺口**（`docs/arac-oc-related-work-gaps.md` 已备）：FEA（仲裁直接
先例）、CBCC-overlapping、OCC（GECCO 2024）、AOS extreme-credit lineage、
DCCC/CCFR/CCFR3（分析节对照）、LCC/LH-CC/RLDO（学习路线展望）。

**诚实边界（必须写）**：dense-overlap 的 Phase-I 曾是 fail-closed 边界；
S5 在线调度未过门；C_j/G_coupled/G_int 不可调度的阴性结论；
仲裁收益目前在高重叠稀疏域以外未验证。
