## 3. 最终架构

```text
Phase-I（冻结）：soft-RDDSM v3 → OverlapCheckpoint
        （共享变量 + owner 集合 + 置信度 + incumbent，不可变）
        ↓
证据驱动派发（冻结）：Gate 41a 两特征规则 → 四动作之一
        ↓
动作执行内部的重叠协议（本方案唯一新机制层）：
  L1 一致性分类器：有界 counted probe（复用 B_j/W_j 仪器）
     逐共享变量判 conforming / conflicting + 置信度
     ├─ conforming → L2a 杠杆优先：
     │    重叠 scope 扫掠加权提前 + 早期有界优先份额
     │    + OCC 式改善传播（邻居获得下一槽位）
     └─ conflicting → L2b 贡献归属 + 有界动态复核：
          校准窗测各 owner 贡献（materiality 口径）
          → 归贡献最大者 → 非 owner 结构性排除
          → 贡献排名翻转持续 m 窗时归属迁移（有界、入 receipt）
        ↓
strict-best archive 写回（不动）：exact FE / fail-closed / hash 链
```

纪律：本层不选动作、不定预算、不做在线 episode 决策——全部规则是
结构证据触发的固定协议。机制总数 = 1 分类器 + 2 支路规则。

## 7. 论文故事线

**定位**：HCC 测 oracle 上界（构造文件直读、零发现 FE，源码级证据）；
ARAC-OC 测**黑盒可达能力**——从零发现重叠、按证据派发、并按
**运行时识别的一致性**对共享变量分类处理。HCC 自留的开放问题
（"更智能的 exploration/exploitation 平衡"）由分析节回应。

**主张清单**（每条挂 gate 编号）：

1. 黑盒重叠发现协议（召回/精度/FE 契约 + 发现谱曲线）；
2. 证据驱动派发（对 HCC 20/4）；
3. **核心**：一致性条件化的共享变量处理——运行时分类（54a）+
   一致型杠杆 / 冲突型归属的二维证据（54b）+ 条件化消融；
4. 分析节：组合收益的存在性（R6）与调度边界（跷跷板刻画、
   象限稳定性、阴性信号链、仲裁可移植性边界）。

**诚实边界（必须写）**：dense-overlap 曾是 fail-closed 边界；
仲裁仅在提案源存在的循环语境有效；在线调度未证明优越；
conforming 支路收益预期在 anytime 而非终值（Blanchard 先例）；
两测试集间只作相对口径比较。

**引用缺口**（已备 `arac-oc-related-work-gaps.md`）：FEA、CBCCO、OCC、
RDG3、Blanchard ORDG、HCC 定位、AOS extreme-credit、DCCC/CCFR/CCFR3、

## 9. 风险与诚实边界

1. conforming 支路收益可能小（Blanchard 阴性结果）→ 判据走 anytime
   指标，"一致型的正确动作是轻触"本身作为发现陈述；
2. 一致性可能随上下文漂移 → L1 默认静态判定，复核开关留消融，
   54a 会暴露；
3. L2b 复核与调度器的边界：复核只管归属迁移，越界即回退；
4. 文献机制为机制级借鉴，数字不可横比（CBCCO/OCC 用 DG2 已知
   结构、CEC2013）；
5. 发生器与 AOB 的参数对齐若做不到完全等值，论文如实声明口径。

## 10. 收尾宣言

v1 方案说"发现、派发、仲裁"是承重墙。Gate 53 证明仲裁不是墙、是
家具——只有在有提案源的房间里才有用。真正的第三面墙是
**一致性条件化**：它把 Gate 53 的失败、vendor 代码的事实、文献里
三个分散的阴性结果和你自己的 conflicting 网格证据，统一成一个
可检验的主张。剩下的事只有两个 gate。先过 54a，再谈其他。
